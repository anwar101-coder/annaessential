# Anna Essentials Website

## Phase 1 — Premium storefront foundation
- Build the responsive home page using the uploaded Anna Essentials logo and all five real product photos.
- Follow the uploaded template’s editorial composition while using Anna Essentials branding, warm cream, natural green, gold accents, and elegant typography.
- Add working desktop and mobile navigation, a strong product-led opening section, three featured products, About, Publications, Location, Contact, and footer sections.
- Make “Order Now” open a clear choice between Telegram and a direct phone call.
- Create a dedicated Products page showing all five products with temporary, clearly editable names, prices, and image-based descriptions.
- Add polished mobile layouts, accessible controls, social metadata, and a favicon derived from the supplied logo.

## Phase 2 — Product management
- Enable Lovable Cloud and create the product database and image storage.
- Seed the five supplied products so the public pages retrieve them dynamically.
- Build secure administrator sign-in and a mobile-friendly dashboard for adding, editing, deleting, publishing, and changing product images.
- Keep roles in a dedicated protected role table and enforce access on the server.

## Phase 3 — Shopping and final verification
- Add the requested cart interactions and product detail experience.
- Test ordering links, navigation, product management, image uploads, and layouts across phone and desktop sizes.
- Replace any remaining temporary product wording when final business copy is available.

## Current scope
Only Phase 1 will be implemented after approval. Phases 2 and 3 will wait for separate approval, matching the requested step-by-step process.

## Technical details
- Use the existing TanStack Start application and Tailwind design tokens.
- Store uploaded site imagery through Lovable Assets; the uploaded reference image remains inspiration only.
- Use Lovable Cloud for later database, storage, authentication, and server-side product management.
